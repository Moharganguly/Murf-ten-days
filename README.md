# ☕ MG'S Cafe - AI Voice Barista

**Day 2 of #MurfAIVoiceAgentsChallenge** | **#10DaysofAIVoiceAgents**

An intelligent voice-powered coffee shop assistant built with LiveKit Agents that takes customer orders naturally through conversation.

## 🎯 Features

- **Natural Voice Ordering**: Customers can place orders by speaking naturally
- **Smart Information Collection**: Gathers drink type, size, milk preference, extras, and customer name
- **Order Management**: Automatically saves orders as JSON files with timestamps
- **Order Status Checking**: Query order status by customer name
- **Multi-AI Integration**: Uses OpenAI for LLM, Deepgram for STT, and Cartesia for TTS
- **Real-time Voice Processing**: Powered by LiveKit with Silero VAD for voice activity detection

## 🛠️ Tech Stack

- **Python 3.10+**
- **LiveKit Agents v1.3.x** - Real-time voice communication
- **OpenAI GPT-4o-mini** - Natural language understanding
- **Deepgram Nova-2** - Speech-to-text
- **Cartesia TTS** - Text-to-speech
- **Silero VAD** - Voice activity detection (optional)

## 📋 Prerequisites

- Python 3.10 or higher
- LiveKit server (included in project or cloud instance)
- API keys for:
  - OpenAI
  - Deepgram
  - Cartesia
  - LiveKit
